# Architecture Decision Records

Use this folder to preserve decisions that affect system structure, data formats, dependencies, or long-term compatibility. Routine implementation details belong in code comments or the relevant developer guide.

For each decision, add a numbered or dated Markdown file with:

- **Context:** the problem and constraints.
- **Decision:** the chosen approach.
- **Alternatives:** the main options considered and why they were not selected.
- **Consequences:** trade-offs and follow-up work.

Keep records concise and link to the affected source or related records. See the [architecture overview](../../ARCHITECTURE.md) for the current system structure.
